# Шаблон карточек урока (Silverwind)

Рабочий шаблон, полученный после долгой доводки в сессии по уроку «Идентичность».
Использовать для любого следующего урока — просто поменять текст, картинки и пересчитать высоту.

## Файлы

- `combined_TEMPLATE.html` — **основной шаблон**, одна широкая альбомная карточка
  1600×N с общей шапкой и двумя колонками (Конспект слева, Задание справа). Это
  финальный формат, который в итоге понравился.
- `konspekt_TEMPLATE.html` / `zadanie_TEMPLATE.html` — более ранний вариант (две
  отдельные вертикальные карточки 1080×N). Оставлены на случай, если снова
  понадобится раздельный формат.
- `fonts/` — самодостаточный набор шрифтов Unbounded + Inter (woff2 + `local-fonts.css`).
  Скачаны один раз с Google Fonts, работают офлайн через `<link rel="stylesheet" href="fonts/local-fonts.css">`.
  **Не удалять и не перекачивать без необходимости** — см. раздел "Технические грабли" в памяти.
- `img-example/` — 4 картинки, использованные в примере (просто референс, для
  нового урока картинки будут другие — см. ниже, как их готовить).

## Как сделать карточку для НОВОГО урока

1. Скопируй `combined_TEMPLATE.html` в рабочую папку сессии, переименуй.
2. Скопируй туда же папку `fonts/` целиком (без неё шрифты не загрузятся).
3. Подбери 3-4 картинки под тему урока (см. `project_leonardo_miro_style` в памяти
   — это та же самая библиотека кристальных изображений на Desktop/Downloads,
   искать по содержанию имени файла, например `gpt-image-2_*female_silhouette*`,
   `*timeline*`, `*age_progression*`, `*hard_drive*`, `*identity_circle*` и т.п.)
4. **Обязательно** прогони каждую картинку (кроме hero, если он полноэкранный
   cover) через скрипт выравнивания фона — иначе будет виден прямоугольный шов
   вокруг картинки:

```python
from PIL import Image
bg = (10, 10, 10); low, high = 10, 42
def match_bg(path, out_path):
    im = Image.open(path).convert("RGB"); px = im.load(); w, h = im.size
    for y in range(h):
        for x in range(w):
            r, g, b = px[x, y]; m = max(r, g, b)
            if m <= low: px[x, y] = bg
            elif m < high:
                t = (m - low) / (high - low)
                px[x, y] = (int(bg[0]+(r-bg[0])*t), int(bg[1]+(g-bg[1])*t), int(bg[2]+(b-bg[2])*t))
    im.save(out_path, quality=93)
```

5. Замени текст в `<div class="col-title">`, `.label`, `<p>`, `.note`, картинки в
   `img/...`.
6. Рендери и подгоняй высоту — см. процесс в разделе памяти
   `project_leonardo_miro_style` → "Пайплайн рендера карточек".

## Точная палитра/стиль (закреплено, не менять без явной просьбы)

- Фон `#0A0A0A`, металлик-акцент `#A8B4BE` → `#d0d8de` (НЕ мятный `#89E6D8`, НЕ
  фиолетовый — это были отвергнутые промежуточные варианты).
- Unbounded для заголовков/лейблов, Inter для текста.
- Заголовок с точкой-разделителем: `ИДЕНТИЧНОСТЬ` (в комбинированной карточке —
  без разделителя, просто одно слово темы урока сверху на фото).
- Свет/тени у самих картинок (не у карточки) — их не трогаем, это часть исходных
  промтов Leonardo.
- Никаких рамок/бордеров вокруг картинок и текстовых блоков — только явные
  разделы через `.label` и тонкую линию `.divider`/`border-bottom`.
