# Шаблон многослайдовой презентации-конспекта

Рабочий шаблон для формата "9-14 слайдов на весь конспект урока" (Природа физической
реальности, Персональная симуляция, Все сценарии уже есть, Ценность, Всё едино —
все собраны по этому шаблону). Не путать с `urok-cards-template` (одна карточка
конспект+задание) и `blok-cards-template` (титульная карточка блока/урока).

## Файлы

- `build_deck_TEMPLATE.py` — Python-скрипт: HTML+CSS слайдов → скриншоты Chrome
  headless → склейка в один PDF через Pillow. Копировать в `deck/` рабочей папки
  урока, менять только контент слайдов (список `slides.append(...)`) и `TOTAL`.
- `fonts/` — самодостаточный шрифтовой набор:
  - `local-fonts.css` — подключает Inter 300 и Unbounded 500 через `@font-face`
    на **локальные** файлы (не гуглошрифты по сети).
  - `manrope-800.ttf` — заголовки (`h1.title`, `.label`) — см. ниже.
  - `inter-300-local.ttf`, `unbounded-500-local.ttf` — тело текста и мелкие
    надписи (`.eyebrow`, `.pagenum`, `.tag`, `.agenda-item .a-title`).

## Важный баг, который уже исправлен здесь — не повторять

**Раньше `h1.title` и `.label` (все заголовки слайдов) использовали `Unbounded`.
Это неверно** — подтверждённый референсный шрифт (сверено с оригинальным
"Блок 1 / Мироустройство", см. [[title-cards-style]]) — **Manrope, начертание 800**.
В шаблоне уже стоит правильный `@font-face` для Manrope и `font-family: 'Manrope'`
на `h1.title`/`.label`. Не менять обратно на Unbounded.

**Второй баг:** `local-fonts.css` в рабочих папках сессии несколько раз либо
отсутствовал, либо был не тем файлом (`fonts_fresh.css` вместо `local-fonts.css` —
ссылка `<link href="../fonts/local-fonts.css">` тогда 404 молча, и Unbounded/Inter
откатываются на системный шрифт — визуально почти незаметно на скриншоте, поэтому
баг долго не замечали). Перед стартом новой презентации всегда:
```bash
ls fonts/local-fonts.css fonts/manrope-800.ttf fonts/inter-300-local.ttf fonts/unbounded-500-local.ttf
```
— если файла нет, скопировать из этого шаблона, не пересобирать с нуля.

## Дизайн-система (CSS-классы в build_deck_TEMPLATE.py)

- `.hero-full` / `.hero-small` — полноэкранная картинка-обложка титульного слайда
  (`.hero-small` — картинка занимает верхние ~70%, не на весь кадр).
- `.split` — двухколоночная верстка: текст слева (`flex:1.25`), картинка справа
  (`.imgwrap`, `max-height:500px`, центр по вертикали).
- `.points-page` — слайд только с текстом (буллеты, без картинки), по
  вертикали центрирован; `.points-page.tall` — прижат к верху (для длинных списков).
- `.bullets.twocol` / `.bullets.twocol.big` — список в две колонки (для
  10+ пунктов, например "прочувствуйте себя" со списком вопросов).
- `.centered` — курсивная цитата по центру слайда (обычно закрывающий слайд).
- `.agenda` — нумерованный список блоков/тем с заголовком+описанием (план урока).
- `.takeaway` — italic-плашка с левой полосой, короткий вывод в конце текстового блока.

Палитра/токены (общие для всей линейки продуктов Silverwind, см. [[lesson-cards-workflow]]):
фон `#0A0A0A`, металлик-акцент `#A8B4BE`→`#d0d8de`, шрифты Manrope (заголовки)
+ Unbounded (мелкие лейблы) + Inter (тело текста).

## Пайплайн сборки урока (весь процесс)

1. Скачать mp3 (может быть в iCloud-заглушке `.Название.MP3.icloud` на Desktop/уроки —
   `brctl download <path>` и подождать материализации).
2. Расшифровать: `whisper "<файл>.MP3" --model small --language Russian --output_format txt --output_dir <папка>` в фоне (займёт 5-20 минут на длинных уроках).
3. Прочитать транскрипт, самостоятельно выделить структуру (не изобретать
   факты — только то, что реально сказано, см. [[feedback_no_inventing]]).
4. Подобрать 2-4 картинки по смыслу из существующей Leonardo-библиотеки на
   Desktop/Downloads (см. [[project_leonardo_miro_style]] про стиль этой библиотеки).
5. Прогнать каждую картинку через скрипт выравнивания фона (см. `urok-cards-template/README.md`
   за точным кодом) — **обязательно, иначе виден прямоугольный шов** вокруг картинки.
   Если Алина жалуется "фон картинки и слайда разного цвета" — это именно
   этот шаг был пропущен или картинка добавлена без повторного прогона.
6. Скопировать `build_deck_TEMPLATE.py` и `fonts/` в рабочую папку, написать
   контент слайдов, `python3 build_deck.py`.
7. Проверить визуально 2-3 самых плотных слайда (Read на .png) на переполнение/
   наложение текста и на реальный шрифт (Manrope в заголовках, не системный fallback).
8. Скопировать финальный PDF на Desktop, отправить через SendUserFile.

## Частые правки от Алины (паттерны, не факты конкретного урока)

- "текст мелкий/крупнее" → добавить класс `.big` к `.bullets` или поднять inline `font-size`.
- Просит добавить/убрать слайд с заданием, вопросы "по сферам жизни" (деньги,
  реализация, отношения, любовь к себе, здоровье, внешность) — устойчивый паттерн,
  который она просит на **разных** уроках, можно предлагать по умолчанию.
- Присылает скриншот Leonardo.ai с новой картинкой прямо в чат — файл почти
  никогда не появляется в Downloads/Desktop сразу; часто оказывается сохранён
  в `/Users/alina/Documents/сайт 1/` (проверять это в первую очередь) или ей
  нужно попросить сохранить его явно ("Save Image As" → Desktop).
